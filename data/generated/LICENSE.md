## Why this licence

The dataset was created using **TurEngMix** as seed data (its training split was the
reference for style and labelling). TurEngMix is licensed under CC BY-NC-SA 4.0, and the
ShareAlike condition requires material built from it to use the same licence.

## What this means

You may share and adapt this dataset if you:

- **Attribution:** credit both this project and TurEngMix (see `CITATION.md` in the
  repository root);
- **NonCommercial:** do not use it for commercial purposes;
- **ShareAlike:** release anything you build from it under the same licence.

## How the data was made

The sentences were written by an AI model and checked with automatic quality checks and a
human annotation study. Details and limitations: `data/generated/README.md`.
